# スケジュールタスク: 週次レポート

## 設定

| 項目 | 内容 |
|------|------|
| タスク名 | 週次レポート |
| 頻度 | Weekly（毎週金曜日） |
| 実行時刻 | 17:00 JST |
| 作業フォルダ | ~/AI秘書/ |

## プロンプト

```
## 週次レポート

今週（月〜金）のブリーフィングファイル（2_areas/daily-ops/briefings/ 内）を読み込み、
週次レポートを作成してください。

含める内容:
1. 今週のハイライト（重要な出来事3〜5件）
2. 完了タスクの一覧（ブリーフィングの✅項目を集約）
3. 未完了・持ち越しタスク
4. 来週の重要予定（Google Calendar参照）
5. 改善提案（今週の業務パターンから気づいたこと）
6. 統計（処理メール数、完了タスク数、ミーティング数）

ファイル名: YYYY-WXX_weekly-report.md（XX=ISO週番号）
保存先: 2_areas/daily-ops/
フォーマット: 3_resources/templates/weekly-report-template.md を参照

また、1_projects/INDEX.md を確認し、今週進捗があったプロジェクトのステータスが
最新になっているか確認してください。
```

## 設定手順

1. Claude Desktop の Cowork タブを開く
2. 左サイドバーの「Scheduled」をクリック
3. 「+ New task」をクリック
4. 上記のプロンプトをコピーして貼り付け
5. 頻度: **Weekly**、曜日: **金曜日**、時刻: **17:00** を設定
6. 「Save」で保存
