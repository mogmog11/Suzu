# スケジュールタスク: ファイル整理・アーカイブ

## 設定

| 項目 | 内容 |
|------|------|
| タスク名 | ファイル整理・アーカイブ |
| 頻度 | Weekly（毎週日曜日） |
| 実行時刻 | 21:00 JST |
| 作業フォルダ | ~/AI秘書/ |

## プロンプト

```
## ファイル整理・アーカイブ

PARA構造に基づき、以下のメンテナンスを実行してください。
**ファイルの削除は絶対に行わないこと。移動のみ。**

1. **完了プロジェクトのアーカイブ**
   - 1_projects/INDEX.md を確認
   - ステータスが「✅ 完了」のプロジェクトフォルダを 4_archive/ に移動
   - INDEX.md のステータスを「📦 アーカイブ済」に更新

2. **ブリーフィングの整理**
   - 2_areas/daily-ops/briefings/ で30日以上前のファイルを確認
   - 4_archive/briefings/ フォルダを作成（存在しない場合）
   - 古いブリーフィングを移動

3. **メモリーの整理**
   - context/memory/glossary.md を確認
   - 今週追加された学習事項を整形・分類

4. **整理レポートの出力**
   - 実行した内容のサマリーを 2_areas/daily-ops/ に保存
   - ファイル名: YYYY-MM-DD_maintenance-report.md

5. **次週の準備確認**
   - CLAUDE.md の情報が最新かどうか確認
   - 更新が必要な場合はユーザーに通知
```

## 設定手順

1. Claude Desktop の Cowork タブを開く
2. 左サイドバーの「Scheduled」をクリック
3. 「+ New task」をクリック
4. 上記のプロンプトをコピーして貼り付け
5. 頻度: **Weekly**、曜日: **日曜日**、時刻: **21:00** を設定
6. 「Save」で保存
