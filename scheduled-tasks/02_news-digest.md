# スケジュールタスク: 業界ニュースダイジェスト

## 設定

| 項目 | 内容 |
|------|------|
| タスク名 | 業界ニュースダイジェスト |
| 頻度 | Daily |
| 実行時刻 | 08:00 JST |
| 作業フォルダ | ~/AI秘書/ |

## プロンプト

```
## 業界ニュースダイジェスト

Web検索で過去24時間のニュースを調査し、3_resources/industry/ にレポートを保存してください。

検索テーマ:
- [業界テーマ1 — ここを書き換える]
- [業界テーマ2 — ここを書き換える]
- [業界テーマ3 — ここを書き換える]

出力形式:
- 各テーマ3〜5件のニュースをピックアップ
- 見出し、1〜2文の要約、元記事URL
- ビジネスへの影響度を★1〜3で評価
- 最後に「今日の注目トピック」を1つ選定・解説

ファイル名: YYYY-MM-DD_news-digest.md（今日の日付）
```

## カスタマイズ箇所

- `[業界テーマ1〜3]` を自社の業界・競合・キーワードに書き換える
- 例: `AI / SaaS市場 / 競合A社 / B2B営業トレンド`

## 設定手順

1. Claude Desktop の Cowork タブを開く
2. 左サイドバーの「Scheduled」をクリック
3. 「+ New task」をクリック
4. 上記のプロンプトをカスタマイズして貼り付け
5. 頻度: **Daily**、時刻: **08:00** を設定
6. 「Save」で保存
