# スケジュールタスク: 朝のブリーフィング

## 設定

| 項目 | 内容 |
|------|------|
| タスク名 | 朝のブリーフィング |
| 頻度 | Weekday（平日のみ） |
| 実行時刻 | 07:30 JST |
| 作業フォルダ | ~/AI秘書/ |

## プロンプト

```
## 朝のブリーフィング

context/memory/context/notion.md を参照してNotionのDB URLとビューURLを確認した上で、
以下を実行し、2_areas/daily-ops/briefings/ に今日の日付のMarkdownファイルとして保存してください。

---

### 1. 今日のタスク（Notionから取得）

**【タスク管理DB — 日常タスク】**
- 「今日」ビューを取得: https://www.notion.so/e6982e3f87bb4e0785754bf32f8a7ddf?v=5f86d43c6ef9403cbe61e66e9c51acee
- ステータスが「未着手」「進行中」のタスクを一覧化
- 時間帯（朝/昼/夜）でグループ化して表示

**【副業タスク管理 — ブログ・YouTube】**
- 「🗂️ ステータス別」ビューを取得: https://www.notion.so/8a07fd759e244f04adb4aa878bb1a50e?v=331180d06e6081a5bfcf000ce3c36fea
- ステータスが「未着手」「進行中」のタスクを優先度順に表示
- 期限が今日以前のものは ⚠️ 期限超過 としてハイライト

**整理ルール:**
- 🔴最優先 / 進行中 → 先頭に配置
- 期限が今日のもの → 🔴 でマーク
- 期限超過のもの → ⚠️ でマーク
- 完了済みは除外

---

### 2. メール要約（Gmail）
- 過去12時間の未読メールを取得
- 優先度（高/中/低）に分類
- 高優先度のメールには返信ドラフトをGmailの下書きとして作成

### 3. 今日のスケジュール（Google Calendar）
- 今日の予定をすべて取得
- 各ミーティングの参加者・議題を整理
- 準備が必要な会議にはアジェンダ案を添付

### 4. Slack概要
- 主要チャンネルの昨晩以降の重要メッセージを要約
- メンションされているものをハイライト

---

### 5. 今日のToDoリスト（統合）

上記1〜4をすべて踏まえ、**1本のToDoリスト**にまとめる。

出力形式:
- 🔴 今すぐやること（Notion進行中 + 期限超過 + 高優先メール）
- 🟡 今日中にやること（Notion未着手優先度高 + 会議準備）
- ⚪ 余裕があれば（Notion 🟢余裕があれば + その他）

---

ファイル名: YYYY-MM-DD.md（今日の日付）
フォーマット: 3_resources/templates/briefing-template.md を参照
```

## 設定手順

1. Claude Desktop の Cowork タブを開く
2. 左サイドバーの「Scheduled」をクリック
3. 「+ New task」をクリック
4. 上記のプロンプトをコピーして貼り付け
5. 頻度: **Weekday**、時刻: **07:30** を設定
6. 「Save」で保存

詳細スキーマ・全ビューURL → `context/memory/context/notion.md` を参照
