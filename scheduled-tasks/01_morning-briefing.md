# スケジュールタスク: 朝のブリーフィング

## 設定

| 項目 | 内容 |
|------|------|
| タスク名 | 朝のブリーフィング |
| 頻度 | Weekday（平日のみ） |
| 実行時刻 | 07:30 JST |
| 作業フォルダ | ~/AI秘書/ |

## プロンプト

```
## 朝のブリーフィング

以下を実行し、2_areas/daily-ops/briefings/ に今日の日付のMarkdownファイルとして保存してください。

1. **メール要約**
   - Gmailで過去12時間の未読メールを取得
   - 優先度（高/中/低）に分類
   - 高優先度のメールには返信ドラフトをGmailの下書きとして作成

2. **今日のスケジュール**
   - Google Calendarから今日の予定を取得
   - 各ミーティングの参加者・議題を整理
   - 準備が必要な会議にはアジェンダ案を添付

3. **Slack概要**
   - 主要チャンネルの昨晩以降の重要メッセージを要約
   - メンションされているものをハイライト
   - 対応が必要なものをリストアップ

4. **今日のToDoリスト**
   - 上記を踏まえた優先順位付きタスクリストを作成
   - 🔴 高優先 / 🟡 中優先 / ⚪ 低優先 の3段階で表示

ファイル名: YYYY-MM-DD.md（今日の日付）
フォーマット: 3_resources/templates/briefing-template.md を参照
```

## 設定手順

1. Claude Desktop の Cowork タブを開く
2. 左サイドバーの「Scheduled」をクリック
3. 「+ New task」をクリック
4. 上記のプロンプトをコピーして貼り付け
5. 頻度: **Weekday**、時刻: **07:30** を設定
6. 「Save」で保存
