# Morning Brief コマンド

## 手順

1. **メール要約**（Gmail）
   - 過去12時間の未読メールを取得
   - 優先度（高/中/低）に分類：
     - 高: 取引先・顧客からの返信待ち、締切24時間以内
     - 中: 社内からの依頼、情報共有で確認が必要
     - 低: ニュースレター、自動通知、CC共有
   - 高・中優先メールに返信ドラフトをGmail下書きとして作成

2. **今日のスケジュール**（Google Calendar）
   - 今日の全予定を取得
   - 各ミーティングの参加者・議題を整理
   - 準備が必要な会議にはアジェンダ案を添付

3. **Slack概要**（Slack）
   - 主要チャンネルの昨晩以降の重要メッセージを要約
   - メンションされているものをハイライト
   - 対応が必要なものをリストアップ

4. **ToDoリスト作成**
   - 上記を踏まえた優先順位付きタスクリストを作成
   - 🔴 高優先 / 🟡 中優先 / ⚪ 低優先 の3段階で表示

5. **保存**
   - `3_resources/templates/briefing-template.md` を参照してフォーマット
   - `2_areas/daily-ops/briefings/YYYY-MM-DD.md` として保存

## 出力例

```markdown
# 朝のブリーフィング — 2026-03-16 (月)

## 📧 メール要約
### 🔴 高優先度
- ABC社 田中様: 「提案書の件」— 先週送った提案書への返信。確認が必要。→ [下書き作成済]

## 📅 今日のスケジュール
| 時刻 | 予定 | 参加者 |
|------|------|-------|
| 14:00 | 週次MTG | チーム全員 |

## ✅ 今日のToDoリスト
1. 🔴 ABC社への返信確認・送信
2. 🟡 週次MTGの準備
```
