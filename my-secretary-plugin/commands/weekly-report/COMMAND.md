# Weekly Report コマンド

## 手順

1. **今週のブリーフィングを収集**
   - `2_areas/daily-ops/briefings/` から今週分（月〜金）のファイルを読み込む
   - 見つからない日があっても続行する

2. **Google Calendarで来週の予定を確認**
   - 来週の重要イベント・ミーティングを取得

3. **週次レポートを生成**
   ```
   含める内容:
   1. 今週のハイライト（重要な出来事3〜5件）
   2. 完了タスクの一覧（ブリーフィングの✅項目を集約）
   3. 未完了・持ち越しタスク
   4. 来週の重要予定
   5. 改善提案（今週の業務パターンから気づいたこと）
   6. 統計（処理メール数、完了タスク数、ミーティング数）
   ```

4. **保存**
   - `3_resources/templates/weekly-report-template.md` を参照してフォーマット
   - `2_areas/daily-ops/` に `YYYY-WXX_weekly-report.md` として保存
   - （XX = ISO週番号 例: W12）

5. **プロジェクトステータス確認**
   - `1_projects/INDEX.md` を確認
   - 今週進捗があったプロジェクトのステータスを更新するよう促す

## オプション引数

- `--week YYYY-WXX`: 特定の週を指定（デフォルトは当週）
- `--send-to-slack`: Slackへの要約投稿（オプション）
