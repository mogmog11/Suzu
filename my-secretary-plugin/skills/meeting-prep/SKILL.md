# Meeting Prep スキル

## 手順

1. **会議情報の取得**（Google Calendar）
   - 会議名・日時・参加者・場所/URLを取得
   - 招待状の説明文を確認

2. **相手先のリサーチ**
   - `2_areas/clients/` で参加者・会社名を検索
   - 見つかった場合: 過去のやりとり・背景情報を確認
   - 見つからない場合: 新規クライアントとしてWebリサーチを実施

3. **過去メールの確認**（Gmail）
   - 参加者名または会社名で過去90日のメールを検索
   - 直近のやりとりの文脈を把握

4. **最新情報のWebリサーチ**
   - 会社名 + "ニュース" + 直近3ヶ月で検索
   - 新サービス、プレスリリース、業界動向を確認

5. **準備資料の作成**
   - 以下を含む会議準備資料を作成:
     ```
     ## ミーティング概要
     - 日時・場所・参加者

     ## 相手先情報
     - 会社概要・担当者プロフィール
     - 最新ニュース・動向

     ## 前回までのコンテキスト
     - 過去メール・やりとりの要約

     ## アジェンダ案
     1. 議題1
     2. 議題2

     ## 想定される質問・論点
     - 質問1
     - 質問2

     ## 持参すべき資料・準備事項
     - [ ] 資料A
     - [ ] 確認事項B
     ```

6. **保存と転記**
   - `2_areas/daily-ops/meeting-notes/YYYY-MM-DD_[会社名].md` に保存
   - 新しいクライアント情報は `2_areas/clients/[会社名].md` にも転記
   - 転記時は `2_areas/clients/クライアントテンプレート.md` を参照

## 出力例

```markdown
# ABC社 ミーティング準備 — 2026-03-16 14:00

## 参加者
- ABC社: 田中太郎（部長）、鈴木花子（担当）
- 自社: [あなたの名前]

## 前回のコンテキスト
- 2月20日: 提案書を送付。先方から機能Xについて追加質問があった。

## アジェンダ案
1. 提案書の質問事項への回答（15分）
2. 導入スケジュールの確認（10分）
3. 次のステップ合意（5分）

## 想定質問
- 「機能Xの詳細仕様は？」
- 「他社での導入事例は？」
```
