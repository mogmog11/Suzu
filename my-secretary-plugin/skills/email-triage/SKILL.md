# Email Triage スキル

## 手順

1. **Gmailで未読メールを取得**
   - 対象: 過去24時間（または指定期間）の未読メール
   - `context/my-profile.md` の VIP送信者リストを参照

2. **優先度判定ロジック**

   | 優先度 | 条件 |
   |-------|------|
   | 🔴 高 | VIP送信者からのメール、返信待ちの返信、締切24時間以内、CC外し不要の直接依頼 |
   | 🟡 中 | 社内からの依頼、確認が必要な情報共有、返信が礼儀として求められるもの |
   | ⚪ 低 | ニュースレター、自動通知、CC共有、FYI系 |
   | 🗑️ スキップ | スパム、重複通知、購読解除すべきもの |

3. **返信ドラフト作成**（高・中優先のみ）
   - `context/style-guide.md` の「メール文体」ルールに従う
   - Gmail の下書きとして作成（送信はしない）
   - 件名: `Re: [元の件名]`

4. **トリアージ結果を保存**
   - ファイル: `2_areas/daily-ops/email-logs/YYYY-MM-DD_email-triage.md`
   - 形式:
     ```markdown
     # メールトリアージ — YYYY-MM-DD

     ## 🔴 高優先 (X件)
     - **送信者名**: 件名 — 要約 → [下書きID: xxx]

     ## 🟡 中優先 (X件)
     - **送信者名**: 件名 — 要約

     ## ⚪ 低優先 (X件) — スキップ
     - ニュースレター X件、自動通知 Y件

     ## 統計
     - 合計: X件処理 / Y件スキップ
     - 下書き作成: Z件
     ```

5. **完了後の報告**
   - 高優先メールの件数と概要を報告
   - 下書きは確認後に送信するよう案内
