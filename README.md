# miiai - 私のすべて

個人的な情報、考え、アイデアをまとめるリポジトリです。

## 構成

```
profile/          - 自己紹介・プロフィール情報
blog/             - ブログのアイデア・下書き
  ideas/          - アイデアメモ
  drafts/         - 下書き
notes/            - 日々のメモ・考え
interests/        - 趣味・興味のあること
goals/            - 目標・やりたいこと
```

## 使い方

各フォルダにMarkdownファイルを追加して、自分の情報を整理していきます。
