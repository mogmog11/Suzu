## タスク取得の優先度ルール

朝のブリーフィングでは以下の順序でタスクを整理する：

1. **副業タスク管理** → 🔴最優先 → 🟡重要 → 🟢余裕があれば
2. **タスク管理DB** → 仕事 → プライベート → スケジュール管理
3. 期限が今日以前のものは **🔴高優先** として先頭に出す
4. ステータスが「進行中」のものは未着手より上に表示

---

## 更新ルール

- タスクの**完了マーク**はNotionで直接行う（AI秘書は書き込まない）
- ただし依頼があれば `notion-update-page` でステータスを変更可能
- 新規タスク追加は依頼があれば `notion-create-pages` で対応
