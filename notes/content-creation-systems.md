# コンテンツ制作システム

Notionに構築済みだが、あまり活用できていない（2026-03-19時点）

## 🎬 動画台本量産システム

Gemini + Manus を使った動画制作パイプライン。

**制作フロー：**
1. **構成作成** — タイトル・テーマ・ターゲット・尺を入力 → Geminiでチャプター分割
2. **チャプター台本作成** — Geminiでシーン指示タグ付き台本を生成
3. **Manus指示書作成** — キャラクター画像・スタイル指定を含む指示書に整形
4. **Manus投入（手動）** — 各チャプターをManusに投入 → Vrew/CapCutで編集

**構成要素：**
- 動画台本量産システムDB（企画〜Manus投入前を管理）
- キャラクター・スタイル定義DB
- AIプロンプト3種（Gemini用）
- 運用マニュアル

## ✍️ ブログ記事量産システム

AI + WordPress を使ったブログ記事制作パイプライン。

**制作フロー：**
1. **構成作成** — タイトル・ターゲット・キーワード入力 → 目次生成
2. **本文執筆** — クローン定義（文体・価値観・ペルソナ）を参照して1000〜2000字生成
3. **画像生成** — Nanobanana用サムネイル画像プロンプト生成
4. **校正・公開（手動）** — AI生成文を編集・肉付け → WordPressに投稿

**構成要素：**
- 記事制作管理DB（企画〜公開を管理）
- クローン定義（知識ベース）DB
- AIスキル3種（プロンプト）
- 運用マニュアル
- 収益データアーカイブ

## メモ

- どちらもNotionにシステムとして構築済みだが、まだ活用できていない
- タスク管理DBには「動画制作を始める（60分）」「ブログ更新（43分）」が未完了タスクとして残っている
- どちらもAIを活用した半自動化ワークフローで、仕組み自体はしっかりしている
